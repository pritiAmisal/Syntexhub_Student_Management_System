# Syntexhub_Student_Management_System

## Description
This Java project is used to manage student records efficiently.
It allows users to add, view, update, and delete student details such as ID, Name, Course, and Marks.
This project is developed as part of internship practice to understand Java and OOP concepts.

## Features
- Add Student Record
- View All Students
- Update Student Details
- Delete Student Record
- Simple Menu Driven Program

## Technologies Used
- Java Programming Language
- OOP Concepts
- Scanner Class
- Command Line Interface

## How to Run
1. Open the project in any Java IDE (Eclipse / VS Code / IntelliJ).
2. Compile the main Java file.
3. Run the program.
4. Follow the menu instructions to manage student records.
